# # Real-Time Static and Dynamic Assamese Sign Language Recognition using Deep Learning

## 📌 Overview

This project focuses on the development of a real-time Assamese Sign Language Recognition system using Deep Learning techniques. The system is designed to recognize both static hand gestures and dynamic sign movements to improve communication accessibility for the Assamese-speaking deaf and hard-of-hearing community.

The project combines computer vision, deep learning, and real-time processing to create an efficient and user-friendly recognition framework.

---

## 🎯 Objectives

- Detect and recognize Assamese sign language gestures
- Support both static and dynamic signs
- Perform real-time gesture prediction
- Improve accessibility through AI-driven communication tools
- Explore deep learning approaches for regional sign language systems

---

## 🧠 Technologies Used

- Python
- OpenCV
- TensorFlow / PyTorch
- NumPy
- MediaPipe
- Deep Learning
- Computer Vision

## 📂 Project Workflow

1. Data Collection
2. Image Preprocessing
3. Hand Landmark Detection
4. Feature Extraction
5. Model Training
6. Real-Time Prediction
7. Gesture-to-Text Output

---

## 🔍 Features

- Real-time hand tracking
- Static gesture recognition
- Dynamic gesture sequence recognition
- Deep learning-based classification
- Assamese sign interpretation
- Scalable architecture for future expansion
